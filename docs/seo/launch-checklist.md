## 3. Проверка после деплоя

```bash
D=https://movemailbox.com
curl -s $D/sitemap.xml | grep -c "<loc>"          # ожидается 31
curl -s $D/robots.txt
curl -s $D/migrate/gmail-to-outlook | grep -o '<title>[^<]*</title>'
curl -s $D/migrate/outlook-to-gmail | grep -o 'name="description" content="[^"]*"'
# описания у двух маршрутов должны отличаться
```

Все URL из sitemap должны отдавать 200:

```bash
curl -s $D/sitemap.xml | grep -o '<loc>[^<]*' | sed 's|<loc>||' \
  | while read u; do printf "%s %s\n" "$(curl -so /dev/null -w '%{http_code}' "$u")" "$u"; done \
  | grep -v '^200' 
# пустой вывод = всё в порядке
```

      Rich Results Test. Ожидаем FAQ и HowTo без ошибок.

## 5. Аналитика — до рекламы, а не после

Это единственный пункт, который нельзя доделать задним числом.
Разметить воронку событиями:

```
measure_started      нажали «замерить объём»
measure_done         объём получен, передать size_gb
paywall_shown        объём больше бесплатного лимита
checkout_started
paid                 передать сумму и size_gb
job_failed           передать код ошибки
```

Без `measure_done(size_gb)` неизвестно распределение объёмов ящиков,
а значит пороги 5/25/100 ГБ — гипотеза, и платный трафик нечем
оптимизировать.
