# MoveMailbox v0.5.0-rc.1

Release candidate for the local utility and closed hosted pilot, not a paid or
public-cloud launch.

- Fixed native packaging: the current RU/EN/UK interface is exported and embedded
  before Go builds. After the UI integration, the old native workflow would
  start the API but serve a homepage 404 when built from current source. The
  published v0.4.0-preview still uses the old interface and is not affected by
  this packaging regression. Docker already exported the new interface.
- Release publication now waits for actual packaged Windows amd64 and Linux
  amd64 demo startup, pages/assets/CSP, selected-folder job completion and SQLite
  history restoration after restart. All five archives are checksum- and
  inventory-checked; runtime files, links and path traversal are rejected.
- Added executable dependency/build information to every archive, and a manual
  candidate-validation workflow that does not publish a release.
- Includes technical work since v0.4.0-preview: HTTP cancellation/read deadlines,
  bounded transient-work protection, closed HTTPS pilot tooling and verified
  disposable Mail-in-a-Box transfer evidence recorded in the handoff.
- Updated SQLite to 1.59.0 after green backend CI.

Native packages do not bundle imapsync. Linux arm64/macOS binaries are
cross-built, not natively run by the release workflow. Artifacts remain unsigned;
licensing still requires the owner's choice. Paid identity/billing, automatic
certificate renewal and public-launch gates remain pending. See
[release acceptance](../RELEASE-CHECKLIST.md) for exact evidence and limits.
