# Работа с двух компьютеров

GitHub хранит код, инструкции `AGENTS.md` и точку продолжения `docs/HANDOFF.md`.
История чата, WSL/Docker, локальные архивы и секреты через Git не переносятся.
Открывать нужно корень клона MoveMailbox, а не произвольную родительскую папку.

## Первый запуск на втором компьютере

Если клона нет, авторизуйте GitHub и клонируйте репозиторий:

```sh
git clone https://github.com/Anton-Babaskin/MoveMailbox.git
```

Откройте папку MoveMailbox в Codex. Если инструкции ещё находятся в незавершённом
PR, они появятся после безопасного переключения на его ветку. Стартовый запрос:

> Работаю со второго компьютера. Проверь локальные изменения, получи все ветки
> GitHub без перезаписи моей работы. Найди актуальный HANDOFF и незавершённый PR,
> безопасно переключись на нужную ветку, прочитай AGENTS.md и продолжи следующий
> технический этап. В конце обнови HANDOFF, выполни проверки, commit и push.

После получения `AGENTS.md` начните новую задачу/сессию, чтобы Codex подхватил
инструкции при запуске, либо явно попросите прочитать их в текущей задаче.

## Как это работает дальше

- В начале задачи агент получает remote-tracking refs **всех веток**. Локальную
  рабочую ветку обновляет только безопасным fast-forward; остальные ветки не
  смешивает и не перезаписывает.
- В конце — проверки, файл передачи статуса, commit, push, проверка удалённого
  SHA и PR. Слияние PR и релиз — отдельные действия с разрешения владельца.
- Не редактируйте одну ветку одновременно на двух компьютерах. Дождитесь push
  перед переходом; для параллельной работы используйте разные ветки.
- Если остались чужие незакоммиченные изменения или история разошлась, агент
  сообщит об этом, а не будет сбрасывать работу.
- Это инструкция на время работы агента, не фоновая синхронизация при открытии
  приложения. На втором компьютере всё равно нужны GitHub-доступ и инструменты
  разработки; тестовые секреты передаются отдельно, вне Git.

Формат выбран по [официальной документации AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md).
