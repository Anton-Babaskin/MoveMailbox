MOVEMAILBOX — WINDOWS PREVIEW
============================

1. Полностью распакуйте ZIP-архив в отдельную папку.
2. Запустите START-DEMO.cmd.
3. Оставьте окно запуска открытым, пока пользуетесь приложением.

Браузер откроется автоматически. Если порт 8080 занят, приложение найдёт
свободный локальный порт или откроет уже запущенную копию MoveMailbox.

Демо-режим безопасен: он не подключается к почтовым серверам и не переносит
реальные письма. imapsync в этот архив не входит.

Для настоящего переноса установите imapsync так, чтобы он был доступен в PATH,
или положите совместимый исполняемый файл рядом с MoveMailbox, затем запустите
START-REAL.cmd. Перед стартом приложение потребует проверить оба подключения.

Если приложение не запустилось:

1. Запустите START-DEMO-DEBUG.cmd.
2. Проверьте файл movemailbox.log в этой же папке.
3. При обращении за помощью приложите последние строки лога без паролей и
   персональных данных.

Запуск от имени администратора не требуется.
